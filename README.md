# 🛍️ Customer Behavior Analysis

## 📊 Project Overview

Customer Behavior Analysis is an end-to-end data analytics project focused on understanding customer purchasing patterns, spending behavior, product preferences, and customer characteristics.

The project demonstrates how raw customer data can be transformed into meaningful business insights using **Python (Pandas), SQL, and Power BI**.

### Project Workflow

**Raw Data → Data Cleaning & Exploration → SQL Analysis → Interactive Dashboard → Business Insights**

---

## 🎯 Business Objective

The objective of this project is to analyze customer shopping behavior and identify patterns that can help businesses better understand their customers and make data-driven decisions.

The analysis focuses on questions such as:

- Which customer groups contribute the most to sales?
- Which products/categories are most popular?
- What are the purchasing patterns of customers?
- How much do customers typically spend?
- How does discount usage relate to purchasing behavior?
- What customer characteristics are associated with different purchasing patterns?
- What insights can help businesses improve customer engagement and sales?

## 🔄 Project Workflow

### 1. Data Preparation

The customer shopping behavior dataset was imported into Python and inspected to understand its structure and data quality.

### 2. Data Cleaning & Exploration using Pandas

**Pandas** was used to prepare and explore the dataset.

Key activities included:

- Inspecting the dataset
- Understanding columns and data types
- Checking for missing values
- Checking duplicate records
- Cleaning and transforming data
- Analyzing customer characteristics
- Exploring purchasing patterns
- Grouping and aggregating data
- Identifying trends and patterns

### 3. SQL Analysis

The prepared dataset was analyzed using **MySQL** to answer business-related questions.

SQL analysis included:

- Filtering data
- Aggregating customer and purchase information
- Grouping data
- Sorting results
- Using conditional logic
- Analyzing product and customer performance
- Answering business questions using SQL queries

### 4. Interactive Power BI Dashboard

An interactive dashboard was created using **Power BI** to present the analysis in an easy-to-understand visual format.

The dashboard provides insights into areas such as:

- Customer demographics
- Purchase behavior
- Product/category performance
- Customer spending
- Discount usage
- Customer ratings
- Key business metrics

Interactive filters allow users to explore different customer and purchasing segments.
